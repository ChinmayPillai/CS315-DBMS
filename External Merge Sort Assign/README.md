# External Merge Sort Simulation
This assignment simulates the external merge sort algorithm

## Usage
```bash
./mergesort <input-file.txt> <No. of keys> <Size of key(bytes)> <Size of block (bytes)> <Memory Size (in blocks)>
```


## Example usage
```bash
./mergesort input-file.txt 10000 4 1024 10
```

If python is installed as *python3* and not *python*
```bash
./mergesort.py input-file.txt 10000 4 1024 10
```

Also:

```bash
python3 mergesort.py input-file.txt 10000 4 1024 10
```

(or)

```bash
python mergesort.py input-file.txt 10000 4 1024 10
```
